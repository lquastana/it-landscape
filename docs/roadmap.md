# Roadmap

## 0.4 — vue métier (actuelle)

- Vue Paysage unique : zones, domaines, processus, applications, lue dans NetBox.
- Indicateurs : hébergement, mutualisation, processus outillés, criticité, interfaces.
- Fiche application avec usages par établissement, échanges et lien vers NetBox.
- Jeu de démonstration au format de l'API NetBox, tests du modèle et des filtres.

## Pistes

- Comparaison côte à côte de deux établissements (convergence).
- Vue « portefeuille » triable (liste des applications avec leurs indicateurs).
- Export PDF ou impression A3 du paysage pour les comités.
- Indicateurs DICP et mode d'authentification lorsque NetBox les porte.
- Traduction anglaise de l'interface.
